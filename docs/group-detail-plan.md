# 照片组详情实现计划
目标：保留现有五场景、工作桌和罗盘，补齐完整组浏览与可选修改。
技术：现有 React / TypeScript / Framer Motion / CSS Modules。
执行：本会话直接执行，需求已由用户明确指定，无新增服务或后续阶段。

- [x] 数据和状态：本地照片地址、示例日期地点；按组保存不可变编辑快照，移出、候补替换、重排、命名、撤销、恢复；印制读取修改后的组。
- [x] 过渡：工作桌选中堆放大居中，其余退场；详情扇形展开。Reduce Motion 仅透明度。
- [x] 浏览：中央照片及相邻露边、滑动和前后按钮、缩略条、点击放大和双指缩放、长按及信息按钮。
- [x] 可选调整：纸质面板；候补和移出照片都在组内处理；拖动及前移后移按钮；重命名支持完成/取消。
- [x] 手机适配：详情专属顶部与底部，100dvh、安全区，visualViewport 键盘避让、对话框焦点管理。
- [x] 验证：状态单测覆盖编辑、撤销、恢复、无效动作、印制快照；Playwright 覆盖三种尺寸、桌面居中、Reduce Motion、真实触摸、拖拽、缩放和原流程。
边界：只保存在当前会话，不实现真实相册/上传/AI；示例拍摄信息明确标注；printing 和 gallery 保留原占位。

验收记录（2026-09-24）：TypeScript 与 Vite 生产构建通过；13 项状态测试通过；35 项原流程/详情浏览器用例及 5 项过渡与返回用例均通过。曾有 2 项用例因两个 Playwright 进程共享产物目录而在收尾时报 ENOENT，已单独重跑通过。覆盖 390×844、375×812、430×932、桌面居中、Reduce Motion。触摸以 Chromium CDP 注入；键盘采用 visualViewport 高度模拟，未做实体 iOS/Android 设备测试。最终主界面和调整面板截图位于 .local/qa。
