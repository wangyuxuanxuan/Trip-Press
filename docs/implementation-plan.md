# 旅印所 · 第一阶段

范围：只实现五个场景、整组选择、轻量确认、本地模拟生成和返回。没有照片分类算法、插画、真实上传、AI、登录、支付或自由画布。用户已明确完整流程与技术选型，直接在当前空目录执行。

采用 React + TypeScript + Framer Motion + CSS Modules。相较多路由页面或自由画布，单空间中的场景状态机能以最少结构提供明确返回行为和镜头转场。

## 结构
- `src/domain`：旅行、照片、完整照片组、作品套装类型。
- `src/data`：83 张本地照片占位记录、示例组、生成步骤及作品工厂。
- `src/state`：带历史栈的 reducer，统一处理场景、整组选择、确认、进度与生成结果。
- `src/components`：空间容器、场景标题、占位块、整组卡片。
- `src/scenes`：tripShelf / workspace / groupDetail / printing / gallery 独立场景。
- `tests`：状态机行为与浏览器验收。

## 执行顺序
1. 建立项目配置与状态机测试，验证测试先失败。
2. 实现类型、模拟数据与 reducer，通过核心流转测试。
3. 实现五场景与共享占位组件；同一容器用平移、缩放、透明度连接；Reduce Motion 关闭空间运动。
4. 验证构建、390×844 和桌面、完整路径、每步返回、取消生成、重复生成与减少动态效果。

## 返回语义
工作桌返回旅行盒子；详情返回工作桌；生成中返回详情并清理计时器；作品墙返回完成状态的生成场景，也提供直接返回工作桌。旅行盒子作为起点没有伪造返回按钮。所有可见交互均产生明确效果，非本阶段功能只以静态说明出现。

## 验收
仅整组选取，确认默认勾选，可取消；生成由本地计时器推进，完成后明确进入作品墙；已生成套装保留于当前会话，可从工作桌重访。刷新重置模拟状态。无底部导航。
