# 已确认的首页与工作桌布局

2026-09-26，依据用户给出的两张设计图实施；仅调整现有项目的首页 collection 和照片工作桌。未重新初始化项目、替换技术栈或更改五场景主流程。

## 界面

- 首页：新照片贴纸标志、白色底面、墨蓝排版、平面打印机导入入口、四本旅行册。导入仍接原有模拟空桌面和导入过程。
- 工作桌：返回、旅行标题和作品墙入口位于固定顶部；四个视角按「这一刻 → 我们 → 一路发现 → 同一种感觉」排列；首个整组封面通栏，余下两列纵向展示。
- 拼贴：真实示例照片、局部裁切、纸页、胶带与 SVG 物件。全部标题、组数量、说明和操作仍是 HTML，不使用整张设计图充当可交互界面。
- 稳定组 ID、分组成员、编辑草稿和计数保持原数据。新视角的显示标签独立于原 category ID。
- 视角切换会回到该视角顶部；从照片详情返回则恢复离开时的工作桌滚动位置。

## 验证

- TypeScript 编译和 Vite 生产构建通过。
- 22 项单元测试通过。
- 25 项浏览器测试通过：4 种手机尺寸和 Reduce Motion 的首页、模拟导入、所有整组入口、视角切换及完整生成返回流程。
- 最终 12 项布局测试通过：上述 5 种配置加桌面居中预览，检查触控尺寸、固定顶部、无横向溢出、导入位置，以及打开封面途中切换视角的取消行为。
- 18 项回归测试通过：正常及减少动态效果下的照片调整、长按、双指缩放、键盘避让、滚动与当前照片恢复、图片加载失败、安全区、旋转和模拟保存分享。
- 已目视检查 375、390、430 宽的渲染截图。安全区与键盘为浏览器注入条件测试，不声称已在实体 iPhone 上测试。

## 仍然是模拟的部分

- 照片来源与贴纸配对为本地示例，尚无照片分析或自动元素提取。
- 青岛、京都、云南为静态预览入口；青岛与云南使用插画样册，没有新增真实旅行照片。
- 分组、导入、生成、保存与分享沿用原型逻辑；刷新仍重置会话状态。
- 详情、印刷、作品墙未在本轮进行视觉重设计。
