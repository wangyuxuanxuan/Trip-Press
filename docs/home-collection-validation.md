## 当前限制与替换边界

- 浏览器图片选择器已实际读取本机照片；没有服务端上传或原生 App 相册桥接。
- 本机预览最长边 1600px；单次最多 120 张、每张 20 MB、总计 200 MB。取消/失败释放临时 Blob URL，取消停止后续解码；原始文件不修改。
- 导入图片、分组编辑、收藏筛选和发布包只保留在本次浏览。刷新后重置；需接本地文件库/数据库实现长期收藏。
- EXIF、AI 分类、配色分析、元素提取、插画和文案生成仍待接入。目前按导入顺序分组，模板配文；演示贴纸明确为手绘示例，不宣称由本机照片自动提取。
- 保存到相册和系统分享仍为模拟反馈；复制与透明 PNG 下载为浏览器本地真实操作。
- 安全区与软键盘测试为模拟浏览器环境。iOS/Android 真机权限、照片格式、峰值内存、硬件帧率、系统返回仍需真机确认。

核心替换位置见 README 的模块表：localTrips.ts（相册/缓存），mock.ts（分类与生成数据），Printing.tsx（生成任务），StickerCollection.tsx（收藏资产），Gallery.tsx（发布结果/系统分享）。
