# 风景样册与主题预览

## 实施范围

- 八本样册：原四本加「海边慢慢走」「沙漠来信」「草原的风」「山野花开」。原五场景状态机未改变。
- 每本相册均有预览，包括大阪；只有大阪提供「打开照片工作桌」。其他样册展示照片与说明，主操作关闭预览，不假装存在尚未实现的整理流程。
- `ShelfTrip.theme` 是统一主题来源，书脊、预览边框、关闭按钮、纸面和主按钮消费同一组颜色。黄色按钮使用深色文字保持可读性。
- 横向书架原生触摸滚动、吸附、隐藏滚动条；提供 44px 左右按钮与键盘方向键。预览关闭后恢复焦点，使用 preventScroll 保留当前位置。
- 原 MobileSheet 的模态焦点、Esc 关闭和键盘避让继续保留，新增可选主题样式，不影响其他场景。

## 素材

新增 8 张 Pexels 风景照片，宽度 960px，JPEG 质量 82，存储于 `public/assets/landscapes/`。页面布局通过 CSS 裁切；未修改人物或虚构摄影地点。文件、作者、来源 URL 和许可链接在 `public/assets/landscapes/attribution.html`，App 预览中也能展开「照片来源与说明」。`src/data/landscapes.ts` 保存供界面使用的结构化来源。

城市名称的旧样册继续使用原照片或插画；新增素材仅分配到风景主题相册，不冒充青岛或云南实拍。打印机三张卡通插画不受本次照片收集影响。

## 验证范围

新增浏览器测试覆盖全部相册预览、统一主题色（含云南黄色按钮）、图片可加载、原生触摸滑动不误开相册、按钮替代操作、Esc 焦点恢复、安全区和大阪两步入口。原有流程测试同步使用预览入口。目标为四种手机尺寸和 Reduce Motion；浏览器模拟不代替实体手机测试。

TypeScript/Vite 构建、22 项单元测试及上述 5 种配置下的 35 项浏览器测试通过；已查看首页、黄色预览、沙漠预览和安全区截图。8 张照片总计 1,296,887 字节，约 1.3 MB。书架仅在左右边界状态变化时触发重新渲染，横滑过程中不逐帧重建所有封面。

## 仍为演示

相册列表与主题为本地数据，尚未接入真实相册导入、分析或主题自动提取；新增样册不拥有真实照片分组与生成任务。添加更多 ShelfTrip 数据即可扩展书架，当前展示八本，不声称已经实现无限数量或跨刷新持久化。
