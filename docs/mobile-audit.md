# 手机原型测试与精修记录

范围：现有五场景、旅行导入子状态、照片组可选调整及作品墙。保留整组印刷主流程，不新增产品功能。

## 验证环境与方法

- Windows Microsoft Edge / Playwright：375×812、390×844、393×852、430×932，另有桌面手机居中预览及 390×844 Reduce Motion。
- 使用 CDP 触摸输入验证滑动、长按、双指缩放和边缘返回。测试安全区变量为顶部 47px、底部 34px；通过 visualViewport 模拟软键盘高度 480px 和 350px。
- 主流程覆盖：旅行盒子 → 大阪 → 工作桌分类切换与成堆 → 整组详情、调整及撤销恢复 → 模拟印刷 → 作品墙预览、排版、配文、模拟保存分享 → 工作桌 → 旅行盒子。
- 异常检查：本地照片请求全部失败、导入取消、印刷失败重试、旋转后恢复、连续操作和返回状态。
- 这些是浏览器模拟测试，不能替代 iOS Safari / Android Chrome 的真机、安全区、键盘、系统状态栏、耗电及热降频测量。

## 已复现并修复

1. 工作桌返回后滚动归零：SceneSpace 在返回时恢复场景滚动，向前进入新场景仍从顶部开始。
2. 当前照片仅保存在已卸载的详情组件：将各组浏览位置纳入现有 reducer，重返详情/从作品墙返回保留当前照片。
3. 主照片按钮以照片 ID 为 key，翻页后卸载焦点节点：保留按钮身份，连续方向键翻页有效，也避免主照片纸框反复卸载和闪烁。
4. 缩略图横滑直接触发排序：触摸横滑仅浏览，长按后拖动排序；鼠标拖动保持原行为；调整面板的前移/后移按钮仍是替代入口。边缘拖动增加持续滚动，抬手/取消/卸载清理计时器。
5. 图片加载失败显示破图：统一 SafeImage 保留尺寸和纸框，显示可读占位，避免无限重试。人物 SVG 贴纸失败显示文字占位，不重绘人脸；透明 PNG 导出失败明确反馈。
6. 手机旋转时详情被压成横屏：触摸设备实际横屏显示竖屏提示，保持原组件和调整；恢复竖屏回到原状态。判断使用屏幕尺寸，软键盘不误触发。
7. 深色系统控件配色未明确：设定 light color-scheme，延用暖白 theme-color 和默认 iOS 状态栏样式；增加 textarea、链接和 summary 的键盘焦点轮廓。
8. 图片解码统一采用 async；非封面的作品墙图片延迟加载，保留邻近照片与缩略图的即时加载，降低翻页等待。
9. 较高软键盘下配文面板发生内部滚动，关闭按钮部分被裁掉：面板标题与关闭按钮改为吸顶，确保完整触控区域，完成/取消仍在可视区域。
10. 长按打开拍摄信息后继续移动会触发背景照片翻页：长按已消费的手势不再执行滑动翻页，弹层中的拍摄信息保持对应当前照片。

## 17 项检查覆盖

| 项目 | 检查方式与范围 |
| --- | --- |
| 刘海 / Home Indicator | 模拟 inset，测量标题、主按钮、面板和作品预览的实际边界 |
| 软键盘 | 标题输入、配文 textarea、完成与取消，模拟两种可视高度 |
| 单手操作 / 触控尺寸 | 检查右侧罗盘、底部场景主操作；按钮不小于 44×44，印制按钮大于 52 |
| 滑动 / 长按 | 主照片翻页与长按信息；缩略图浏览和排序分离；双指缩放及按钮替代 |
| 返回 / 滚动 | 顶部按钮和边缘手势；模态期间禁用场景手势；返回恢复滚动与当前照片 |
| 动画 / 图片内存 | transform/opacity 动画，无粒子动画；资源盘点与单独浏览器采样 |
| Reduce Motion | 照片/场景空间运动降级，保留阶段文字与淡入，禁止振动 |
| 深色系统 | 暖白背景、light color-scheme、状态栏 metadata；实际系统栏待真机验证 |
| 图片加载失败 | 中断所有 JPEG 请求，检查占位与主流程、透明 PNG 导出错误反馈 |
| 屏幕旋转 | 横屏提示；旋转回竖屏保留照片与调整；键盘不视作旋转 |
| 保存分享 | 单张、整套、作品分享及配文分享均明确模拟，不声称已保存或已发布 |
| 状态恢复 | 返回保留分类、组名/顺序/照片调整、当前照片、作品排版和三种独立配文；刷新不持久化 |

## 图片资源盘点

12 个 JPEG 文件，合计 2,940,417 字节（约 2.80 MiB）；最大 960×1440。
全部按 RGBA 解码的像素数据合计 37,518,480 字节（约 35.78 MiB）。这是静态估算，不含纹理、GPU、副本、浏览器缓存及 JS 堆，不能当作实测峰值。
83 张照片记录复用本地示例图片；真实 83 张手机原图尚未进行压力测试。接入时需要分辨率分级、缩略图缓存、解码并发限制及原图按需读取。

独立 Windows Edge 开发预览采样（393×852，无其他浏览器测试同时运行）：

- 连续十轮进入照片组、切换照片、返回工作桌，并逐轮请求 GC；DOM 节点保持 342，监听器首次预热后保持 364。JS 堆从约 5.72 MiB 到 7.20 MiB，后六轮增加约 0.22 MiB。短测不能证明无泄漏，也不包含解码图片/GPU 内存。
- 分类切换采样 124 个帧间隔，中位数 16.7ms、P95 18.4ms，1 个超过 50ms 的间隔，PerformanceObserver 未记录长任务。不把该数据视为手机稳定 60fps 的证明。
- 350px 可视高度下标题与配文输入可见，完成按钮底边分别约 310px、349.92px。补充测试验证吸顶后的关闭按钮完整可触摸。
- 原始采样记录见 `docs/mobile-audit-metrics.json`。

## 仍需真机确认的限制

- 当前为 Web 手机原型，没有真实相册、AI 分析、生成服务或系统保存/分享桥接。
- 刷新、关闭或系统回收页面后状态重置；已修复的是同一会话内的返回恢复。
- CSS/metadata 不能强制所有浏览器锁定方向、隐藏浏览器工具栏或控制原生状态栏；当前用横屏提示保留竖屏体验。
- 真机帧率、峰值图片/GPU 内存、iOS 交互式返回与辅助技术仍需实机验收。
