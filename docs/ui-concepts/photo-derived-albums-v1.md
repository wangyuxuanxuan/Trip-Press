# 旅印所：照片拾色与照片贴纸 UI 方案 V1

本文件记录视觉概念，未修改运行中的 App。图片由内置 imagegen 生成；不是已接通照片识别服务的产品截图。

## 视觉原则

- 界面固定使用白色 #FFFFFF；保持深色高对比度文字。相册色彩作用于纸边、胶带、标签、印章按钮和贴纸，不改变整个界面的底色。
- 每趟旅行建立独立配色：从照片中选出一个主色、两个辅助色和少量强调色。暗部、肤色和低饱和噪声不直接决定 UI 背景；界面应保持清透明亮。
- 每枚内容贴纸都应关联来源照片及对象区域。没有照片依据时，不添加通用飞机、花朵等旅行装饰充当提取结果。
- 建筑和物件可以平面插画化；人物保留真实摄影裁切，不能用插画重绘面孔。
- 真实照片占视觉主位，贴纸与插画用于强化旅行记忆。
- 导入入口位于旅行盒子顶部，操作仍以完整照片组为单位，无底部导航栏。

## 三屏结构

1. 旅行盒子：顶部导入信封；不同旅行以照片封面、主题色纸边和来源贴纸呈现独立身份。
2. 照片工作桌：完整照片堆、右侧分类罗盘、轻量配色提示。沿用现有核心路径。
3. 作品墙：上方真实照片，下方同场景提炼插画，周围排列对应物件贴纸；保留配文、保存和分享场景操作。

## 后续实现边界

相册拾色、对象分割和衍生插画目前只是本方案提出的视觉规则，并未连接真实服务。正式实现时应保存主题色和对象的来源关系，避免每次打开相册时主题随机改变；同时校验文字与按钮的对比度。当前阶段只提交方案图，不改变原型流程。
