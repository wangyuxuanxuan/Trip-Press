# 旅印所 UI 概念 V2：清透白底与整洁排版

本轮针对 V1 的配色、字体、信息层级和装饰密度进行视觉修订。只生成评审图，不修改运行中的 App。图像使用内置 imagegen 生成。

## 修订规则

1. 界面底色统一 #FFFFFF。移除泛灰底纹、旧纸效果、厚阴影、手写批注和夸张胶带。
2. 使用同一套中文无衬线字体。建议界面落地使用系统苹方或 Noto Sans CJK；标题 26px、分组标题 19px、正文 15px、辅助信息不小于 12px。界面文本水平排列，保持统一左侧基线。
3. 主要侧边距 24px，间距采用 8/16/24px。照片和标题同轴；照片堆背页可轻微错位，文字不倾斜。
4. 照片拾色分为“来源色”和“界面应用色”。保留来源色相，调整界面应用色的明度与彩度，避免照片暗部成为按钮或大面积底色。正文统一使用深蓝灰 #243849。
5. 大阪示意应用色：鲜桃珊瑚 #FF876E、浅晴蓝 #70D6ED、小面积柠檬黄 #FFE788。绿色相册参考明亮叶绿 #79CBA0。每本相册一个主色，一个主要辅助色，其他颜色只作小面积点缀。
6. 贴纸保留照片来源原则，减少到每个相册或主体作品 1—2 个关键物件。人物保留摄影，店铺插画不重绘人物。
7. 统一品牌字体，照片与印刷机组合标识简化为清晰小图形。

## 保留的流程

- 顶部导入入口。
- 旅行盒子 → 完整照片组工作桌 → 作品墙。
- 分类罗盘存在，但弱化大面积四色拼盘，突出当前分类。
- 作品墙保留真实照片、对应物件插画、配文和场景操作。
- 无底部导航，不增加产品功能。

## 评审边界

这是一张生成式视觉方案图，字体与尺寸为落地方向，不是经过实机验证的界面参数。图片中的字形、数值、建筑细节不应当作最终资产。尚未实现真实自动拾色、物件分割或动态主题；正式落地需要对文字对比度和手机可读性逐项验证。
