# 作品墙实现计划
目标：沿用现有移动 App 与状态管理，将 gallery 占位替换为真实纸张展示墙。
参考图未在本轮可读上下文中显示，采用用户明确给出的构图、色板与纸张要求。
- [x] 数据：每版作品保存照片快照；10件作品（封面、六张轮播、贴纸、拼贴、配文）；三种排版及三种配文分别持久保存在现有 reducer。
- [x] 视觉：带胶带、图钉、夹子的错位展示墙；实拍与对应 SVG 街景插画上下对照；延用八种旅行贴纸，真实人脸保持摄影图像。
- [x] 预览：从点击作品的位置放大至前景，轻微虚化背景；关闭还原位置、滚动与焦点；Reduce Motion 仅透明度。
- [x] 轻编辑：排版、标题、配文切换/修改/复制；保存单张、整套、分享明确给出模拟反馈。
- [x] 导出：本地 SVG 转透明 PNG，内嵌人物照片，下载透明贴纸合集；不接真实保存/分享 API。
- [x] 导航：保留原返回链，新增返回本版照片组与工作桌；空作品墙仍可返回。
- [x] 验证：生成快照、编辑持久性、导航、模态焦点、布局、安全区、无横向溢出、实际 PNG 透明度、模拟反馈、原流程回归。
仅实现本阶段，不增加复杂编辑器、传统列表或真实 AI。

验证结果：TypeScript 编译与 Vite 生产构建通过；19 项单元测试通过；65 项 Playwright 回归通过（三种手机尺寸、桌面居中预览、Reduce Motion）。实际下载 PNG 为 1140×1320，透明角像素 alpha=0，八个贴纸区域均有像素，人物区域保留摄影色彩。人工查看封面、拼贴、配文、两种替代排版和带 47px/34px 安全区的贴纸预览。
