# 作品生成场景
本轮保留现有场景、照片组编辑与视觉系统，只实现 printing。
- [x] 状态：四阶段、运行/失败/完成；失败重试不丢失选组；取消清理计时；完成仅创建一次作品，自动进入 gallery；从 gallery 返回完成页不再次跳转。
- [x] 时间：各阶段 950ms，共 3.8 秒，完成出纸停留 350ms 后跳转。Reduce Motion 相同阶段与时长，只有透明度变化。
- [x] 组件：旅行元素 SVG、真实人物照片纸贴、插画机器、输入整叠照片、成品出纸。仅 transform/opacity 动画。
- [x] 失败：略皱纸张与指定文案，重新印刷；提供标明演示的失败触发按钮，无随机失败。
- [x] 验证：状态测试、浏览器时长与阶段、取消/返回/重复操作、失败重试、三手机尺寸、桌面居中、Reduce Motion、截图。
素材/数据为本地演示。人物保留摄影图像，不绘制替代人脸。图库内容保持现有占位。

验收：TypeScript 与 Vite 生产构建通过；16 项状态测试通过；40 项既有浏览器用例回归通过。新 printing 的 10 项浏览器用例在最终复测中全部通过，覆盖 375×812、390×844、430×932、桌面居中和 Reduce Motion。以浏览器点击事件与 gallery DOM 出现时间记录 3–5 秒约束。初次回归存在计时累计延迟和宿主测试等待误差，已改为统一 performance.now 时间线及浏览器内测量。Reduce Motion 采用静态错位纸张，避免完全遮挡。独立只读审查完成。

范围：八种元素和人像均为本地模拟演示；人像来源、作者及许可见 public/assets/photos/credits.json 和 attribution.html。没有真实 AI 提取，没有扩展 gallery 内容。
