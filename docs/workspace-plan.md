# 手机照片工作桌

保留现有外壳、视觉变量、五场景与reducer。工作桌专属顶部包含纸签返回、居中旅行名称、日期/83张、纸签作品墙入口。主体为纵向轻滚动的固定构图桌面，无自由画布；每模式4–5个完整照片堆。右侧中部罗盘与照片堆预留不重叠区域，右下印刷机仅为静态提示。

数据：13个唯一照片组，通过分类索引映射成推荐5、颜色4、人物4、主题5组；跨分类同名组共享ID与photoIds。workspaceMode存入现有reducer，返回详情后保持模式。作品墙入口接入现有gallery；无作品只加基础空态。

罗盘：四个44px以上radio按钮，可点击、方向键、Home/End、辅助技术切换；中心短拖动选择最近方向并吸附。拖动阈值18px，pointercancel重置；按钮作为手势替代。

成堆：每组4层错位纸照片，稳定坐标构图；切换使用先散开后聚拢的transform/opacity动画，避免滤镜动画、粒子和大量layout动画；Reduce Motion只淡入淡出。快速切换显示最后一次模式，退出场景清理动画。

测试先行：分类数据和模式持久、全部照片组入口、罗盘按钮/键盘/触摸短拖/取消/快速切换、动态效果降级、手机边界与不重叠、原有完整流程。验证后停止，不新增托盘、印刷逻辑和作品内容。
